## Accessing the Platform

Visit [primimarket.com](https://primimarket.com) to access the Primi platform. No account is required to browse index data.

## Exploring Indices

The homepage displays all active indices tracked by Primi. Each index card shows:

- **Current value** and **daily change**
- **YTD performance**
- A sparkline chart of recent price history

Click any index card to open the full detail view.

## Reading the Detail View

The index detail page includes:

<Steps>
  <Step title="Price Chart">
    An interactive chart showing index performance over time. Toggle between 1W, 1M, 3M, 1Y, and All-time views.
  </Step>
  <Step title="Constituents">
    The full list of companies currently in the index, along with their individual weights and price data.
  </Step>
  <Step title="Data Sources">
    A reference to the data sources powering the index calculation.
  </Step>
</Steps>

## Exporting Data

Primi supports CSV export for all index data.

1. Open any index or constituent view.
2. Click the **Export CSV** button in the top-right corner.
3. The file will download with all visible data in spreadsheet format.

## Filtering and Sorting

Use the controls at the top of any data table to:

- **Sort** by name, price, change, or weight
- **Filter** by sector or market cap tier
- **Search** for a specific company by name or ticker

## Understanding the Numbers

| Term | Definition |
|---|---|
| **Index Value** | The calculated level of the index at close |
| **Daily Change** | Point and percentage change vs. the prior close |
| **YTD** | Year-to-date return from January 1st |
| **Weight** | The constituent's share of the total index value |
| **Float-Adjusted Market Cap** | Market cap calculated using only publicly tradable shares |
